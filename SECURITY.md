# Security Policy

## Supported Versions

We actively provide security updates for the following versions of **FindThaGame**:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

As FindThaGame is continuously deployed to production, we recommend always running or deploying from the latest `main` branch.

---

## Reporting a Vulnerability

We take the security of FindThaGame and user privacy seriously. If you discover a security vulnerability or sensitive data exposure, please report it responsibly.

### How to Report

1. **GitHub Security Advisory (Preferred):**
   Submit a private report via [GitHub Security Advisories](https://github.com/kbtale/findthagame/security/advisories/new). This allows us to collaborate securely without public disclosure.

2. **Email:**
   Send an email to [cebemind@hotmail.com](mailto:cebemind@hotmail.com) with the subject:
   `[Security] FindThaGame Vulnerability Report`

### What to Include in Your Report

Please include as much detail as possible to help us reproduce and remediate the issue quickly:
- Type of vulnerability (e.g., API key leak, XSS, SSRF, injection).
- Step-by-step instructions or proof of concept (PoC) to reproduce the vulnerability.
- Any relevant logs, screenshots, or code locations.
- Potential impact of the issue.

### Response & Resolution Timeline

- **Initial Response:** We will acknowledge receipt of your report within **48 hours**.
- **Assessment & Fix:** We will keep you informed of our progress towards a patch and provide status updates every **7 days** or sooner.
- **Public Disclosure:** We ask that you give us reasonable time to release a patch before disclosing any details publicly. Once resolved, you will be credited in our release notes (unless you prefer to remain anonymous).
